# 实验收益对照与失败诊断

基线dc109a6 / 1.7.0，交付1.8.0。新增只读CLI `node benchmarks/report.mjs --out <实验目录> [--format json|markdown]`，默认JSON；API `createComparisonReport({outputDirectory})`。仅单个已完成、严格v4协议且通过现有完整审计的实验，支持paired/reference，strong-reference仅作为冻结配置中的参考组，不参与弱模型两组配对。无需当前CLI身份或源码一致，不读取协议自报外部路径，不执行模型。

按taskId/trial配对，不依赖保存顺序。功能、共同交付和完整交付分别给出baseline-only / harness-only / both-pass / both-fail数量，完整交付明确含Harness额外门禁。逐试次输出结果相对路径、失败类型及原始已知度量，差值统一为Harness减baseline。失败类型是可观察条件，可重叠，不声称模型/网络根因。

耗时、工具数、输入/输出Token分别保留未知，只有两侧均有合法值才计算差值；合法数必须有限且非负，计数还需安全整数。汇总显示配对覆盖数量及差值中位数。超时和工具预算截断独立标记，耗时仅描述实际观察到的区间，不认定截断样本更快完成。已有工具类别作为本地事件计时展示，不相加成总耗时；无计时信息为null。旧分组统计及其持久化字段保持。

通过可选readEvidence读取器把audit/audit-trial/execution已有审计的全部文件读取传到报告入口。默认调用路径行为不变。报告读取器复用严格路径读取，记录首次内容哈希（包括可选文件缺失），重读发生变化即拒绝，结束时复查全部实际读取文件；失败路径同样复查。锁只读inspect，free/stale可检查，其他状态阻塞；成功前复核代次，变化撤销结果。不创建/回收锁，不写文件，不返回半份比较报告。此为前后观察，不能保证报告返回后文件永不变化；审计证明内部一致性，非外部可信执行证明。

JSON/Markdown仅包含配置、摘要与相对结果路径，不包含候选/日志正文或原始异常消息；复用递归脱敏，Markdown转义用户字段。退出码0为报告成功，2为未完成/旧协议/锁或读取变化，1为参数或无效证据；失败无pairs。配对数量受冻结协议最大重复数和固定题集约束，完整列出配对结果。

验证：先建立报告正反例红测试，再实现。用真实生产runExperiment加模拟driver建立v4夹具，检查配对旋转顺序、失败样本、截断/缺用量、合法零、非法数值、三组参考、损坏/缺文件/链接、读取竞争及异常路径、只读写入钩子、CLI退出码和Markdown脱敏。完整Runtime与既有评测回归，独立高风险复核后收尾。无数据库/配置凭据影响；无付费模型实验。Windows使用既有Node20与D盘TEMP，所有控制面仅经CLI维护。
