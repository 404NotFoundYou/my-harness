# AI Harness 1.3.0 优化交付

基于用户“根据建议进行优化”的授权实施。最终产品快照：`a02edcf2d41105d11f7328a4b841cee589253833598037f6757eba16b3673ca0`；本地 Windows / Node.js 22.20.0。

## 已实现

- 统一三个评测驱动的完成条件，拒绝损坏协议、失败终态及非法最终结构；结构化脱敏后仍可从事件日志与最终文件重建判定，审计同时核对逐条摘要及聚合统计。
- 新增 `lock-status` / `lock-recover`。新格式锁具有所有者和代次；恢复保持排他并先检查记录，释放先整体移走目录，避免中断后留下无主锁。损坏控制面保留现场并拒绝继续写入。
- 明确指定的普通 UTF-8 文本支持多语言文件，遗漏原因可见；自动依赖发现继续限于 JS/TS 的局部范围。
- BUGFIX 获得统一 `finish` 引导；`guide --brief` 减少重复输出，保留实际判断、证据和未完成阶段。
- 检查可映射 `A1` 等验收编号，映射参与计划签名；`record --artifact` 保存带哈希的证据副本并校验漂移。
- 评测增加同模型双组、重复试次、预设预算和 dry-run；统计交付维度、区间、耗时与协议失败。原三题和历史九样本审计保持兼容。
- 增加源仓库专用 Windows/Linux CI，并同步 README、使用指南、任务引导、架构及评测说明。
