# 固定任务对照设计

用户已授权复用现有 CLI 登录并小规模真实运行。可用性 smoke 已验证 gpt-5.6-luna 与 gpt-5.6-sol 返回 READY；正式实验按 CLI 配置的模型 ID 记录，不声称验证了第三方服务内部权重或计费。

三组：weak-baseline（Luna，无 Harness）、weak-harness（同一个 Luna，加 Harness）、strong-reference（Sol，无 Harness）。统一 medium 推理档、每次独立临时 Git 仓库、workspace-write 沙箱、相同公开任务/源文件/允许修改范围/公共测试，统一时间与工具调用预算。保留模型真实 JSON 事件、最终完成声明、CLI 上报用量、失败和超时，禁止把模拟驱动的数据混入真实报告。

固定任务初稿：CSV 记录解析（引号、换行、空字段及 BOM）、整数金额分配（守恒与确定性余数分配）、增量事件合并（版本、重复与不可变输入）。每个任务提供公开规格与少量公共测试；独立验收在模型退出后运行，测试与判定代码不放入参与者工作区。验收要求完成标记与测试计数，不能把单纯 exit 0 当作通过。

先做小规模先导运行收集失败分类，再针对失败补代码上下文和验证工具；最终三组使用同一固定任务版本与验收集合。报告分别列功能验收、范围违规、错误完成声明、Harness 工作流状态、耗时和 token，用量不是货币成本。若需要开发/留出分组，三组在每个分组内使用相同输入，避免对失败用例修改后只测同一题造成误导。

Harness 帮助应来自公开资料与确定性工具：读取受影响实现、直接调用方、既有公共测试和约束；从真实失败输出定位代码；提供结构化、可版本绑定的验证。不得注入隐藏答案，不通过改变基线模型/预算/任务来制造提升。

本文件只记录后续实验设计，尚未声称正式对照已执行。

## 试跑约束

每组每题一个独立会话；顺序按任务轮换组别，统一 medium 推理档、180秒墙钟预算、80个工具调用上限，无自动重试。默认三题九次调用。开发集为 CSV 和整数分配，增量合并作为留出任务；补充工具时只根据开发集失败，留出题不用于调参。失败也保存结果，不因模型未完成而删掉样本。CLI模型ID与用量按服务返回记录，不验证自定义服务后端权重，也不换算价格。

任务中只开放指定实现文件和新增自测文件；公开规格、调用方、原有公共测试保持相同。隐藏验收代码放在独立判定目录，模型结束后复制实现到新的判定目录运行。判定结果必须同时有随机完成标识、预期用例ID全集和真实成功结果；进程提前exit(0)、丢日志或测试不完整都不能通过。

CSV 任务保护记录边界、字段空白、空字段和引号内换行；整数分配保护精确守恒、稳定余数排序、安全整数边界及输入不变；增量合并保护版本单调性、删除墓碑、重复事件幂等和输入不变。公开规格是验收权威，隐藏测试不得引入未公开要求。

一次实验的产物包括：配置与任务哈希、候选代码、prompt、结构化完成声明、JSON事件、脱敏stderr、用量与耗时、工具数/超时/退出码、文件范围变化、隐藏用例结果、Harness终态与CI检查。模拟驱动仅用于框架单元测试，报告明确real或simulated，不混用统计。
