# 新项目策略

- 从批准输入提取用户、角色、核心流程、平台、非目标和质量约束。
- 在数据库、任务计划和编码前创建 v1.0 文档基线。
- 架构来源必须是 `HUMAN_PROVIDED` 或 `AI_RECOMMENDED`，不能混为责任不清的折中方案。
- 人类架构优先；发现不可实现、版本冲突、安全风险或与 PRD 冲突时给出证据并请求决定。
- AI 推荐覆盖客户端、后端、API、鉴权、数据、第三方、配置、构建、部署、可观测性、恢复、安全和测试；未知规模、预算和团队能力必须列为假设。
- 默认选择满足当前 PRD 的最简单完整架构；没有独立扩缩容、隔离、所有权或团队边界证据时不默认微服务、多数据库或事件总线。
- 完成业务/领域/API 技术设计后，先做数据库决策，再生成带依赖的纵向任务计划。
- 先实现可运行的端到端纵向切片，再扩展；禁止为未来假设预建复杂框架。
