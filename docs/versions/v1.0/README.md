# v1.0

- 状态：实现与自动化验证完成，待独立复核和发布确认
- 前一版本：无
- 批准输入：用户要求将空项目整改为可复制、可稳定强制执行的 Harness runtime

## 目标

交付零第三方依赖的仓库内 CLI、结构化工作状态、确定性门禁、命令策略、证据记录、测试、安装器和 CI 入口，并将根规则拆成核心与按需策略。

## 非目标

- 模型 API 调用和对话循环。
- 远程数据库或控制面。
- 自带多代理调度器。
