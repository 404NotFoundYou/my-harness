# 整库复审改进

- CI 接受完整基准提交并按提交窗口检查路径。仅当前窗口中新建或更新且证据有效的交付可覆盖变化。同一窗口只有一个既有 Markdown 文件的内容变化时，可在提交 trailer 显式声明路径，由项目审查确认其语义。保持本地快照校验和历史终态验证。
- 安装遍历前排除工作项与备份，按旧收据内容判断原版文件升级和退役，复用现有备份与回滚。修改过的退役文件显式冲突。新项目校验文档非空白。
- Runtime 单次检查内复用工作项和验证读取。评测持锁期间逐项校验，初始、恢复、失败及结束全量复核。新统计统一完整用量判断，保留冻结版本语义。
- 保存上一轮已跟踪实验目录的字节归档，保留清单并验证可还原和审计。合并相同开发状态表和文件写入实现。

无数据库影响。通过定向负例、Runtime 回归、无模型评测回归、历史审计兼容和独立审查验收。
