## 安装后烟测

测试在新建临时 Git 仓库中通过真实子进程完成：

1. `install --target` 创建 Runtime 文件。
2. `init --mode existing --docs existing` 初始化项目。
3. 建立 Git 初始提交并执行 `doctor`。
4. 创建 `ITERATION` 工作项，完成基线、技术设计、数据库 `none` 决策、计划、任务、验证、任务 Review、最终验证、文档结论、最终 Review 和验收。
5. 进入 `DONE` 后执行 `check --ci`，退出码为 0。
6. `guard` 的稳定退出码为 allow=`0`、ask=`2`、deny=`3`；无架构来源的新项目和错误任务阶段命令返回 `1` 及结构化错误码。

## 故障注入

- 绝对路径、父目录逃逸、符号链接写入被拒绝。
- 已有三类规则文件无损合并；兼容导入不改写；重复安装字节幂等。
- 托管块篡改默认失败，force 只修复有效块；损坏/重复标记即使 force 也失败。
- 普通文件冲突在规则合并落盘前失败；修改已有文件先备份；备份和源项目私有规则不会再次分发。
- 合并后根规则超过大小上限时零写入失败；空规则文件也会在修改前备份。
- 嵌套 shell、破坏性 Git 和解析失败命令为 deny；外部变更为 ask。
- 显式路径同名程序不能伪装允许工具。
- 新项目缺架构来源/批准、BUG 缺实际/期望/复现、数据库设计未完成、multi 计划缺策略标志均被拒绝。
- 非终态/阻塞工作项、伪造证据 ID、错误策略文件路由和越界写入使检查失败。
