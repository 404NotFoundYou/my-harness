# 终态分析命令证据的历史快照

`ANALYZING` 中引用命令必须属于本项当前修订，按只读白名单成功运行，执行前后在当前源码上快照一致；回答前源码漂移仍拒绝。`ANSWERED` 已在转态时通过门禁，后续合法源码版本不应使历史回答失效。

在转 `ANSWERED` 前，以一次源码捕获作为回答时证据点，再以同一捕获复核所有引用命令，保存为现有 result 可选字段 `analysis.source`。终态复核此带内容哈希的引用及每个命令的前后快照，不再对照当下源码。`verificationReport` 等开发型校验维持原逻辑。旧记录缺回答锚点时，优先使用同摘要的已有基线快照；若基线不同，只能从完整命令前后快照及转态历史复原当时的自洽性，无法证明回答时绑定，不能据此做高风险新决策。旧记录正常CLI事实继续可读，不伪造出当年不存在的锚点。

回归涵盖回答前漂移拒绝、回答后新提交可审计、新锚点拒绝成对替换、旧记录基线一致及A→B→C基线不同两种路径。快照捕获是证据时点；状态落盘前后其它进程可能改工作区，Runtime无全局文件系统锁或外部防篡改签名，不承诺阻止有权改写全部控制面的恶意进程。无数据库影响。
